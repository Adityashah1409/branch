# Changelog

## 20.0.1.0.0 (2026-09-26)

First release for Odoo 20.0.

* `branch_management`: branch master (hierarchy, per-company code, address,
  logo), allowed/default/current branch per user, User/Manager/Administrator
  groups, systray branch selector, `res.branch.mixin`, optional branch
  sequences, Assign Users wizard, printed-document branch block.
* Integrations: account, sale, purchase, stock, mrp, point of sale, crm, hr,
  project, partner, plus the auto-installed bridges sale_stock,
  purchase_stock and pos_stock.
* Automated tests for TC-001 to TC-025, a browser tour, and GitHub Actions CI.
