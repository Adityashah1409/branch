# Developer guide

## Layout

```
website_aurora20/
  models/        aurora.product.brand, website settings, product B2B guards,
                 homepage design generation
  controllers/   /brands, /brand/<slug>, /aurora/quick_view, /aurora/cart/drawer,
                 /aurora/brands/snippet, /shop brand filter
  views/         backend views, frontend templates, snippets, page designs
  static/src/    interactions (quick view, cart drawer, recent searches,
                 brand logos, countdown), SCSS, editor options
  tests/         Python tests and a browser tour
theme_aurora20/
  models/        theme.utils: header/footer registration and post-copy
  data/          theme assets (primary variables, Bootstrap overrides, styles)
  views/         8 headers, 8 footers
  static/src/    SCSS per area, editor plugin, thumbnails
```

## Odoo 20 APIs used (verified against 20.0 source)

* Frontend code: `Interaction` (`@web/public/interaction`) in the
  `public.interactions` registry. Interactions only start inside `#wrapwrap`,
  so the quick view dialog and the cart drawer are rendered there.
* Header/footer choices: a `website-plugins` plugin providing
  `header_templates_providers` / `footer_templates_providers`
  (`HeaderTemplateChoice`, `FooterTemplateChoice`).
* Mutually exclusive templates: `theme.utils._header_templates` and
  `_footer_templates` properties.
* Theme presets: `$o-website-values-palettes`, `$o-color-palettes`,
  `$o-theme-font-configs` in `web._assets_primary_variables`.
* Page designs: manifest `new_page_templates`, generated by
  `ir.module.module._generate_primary_snippet_templates` and
  `_generate_primary_page_templates`. The latter is overridden for this module
  because the standard one only formats keys of `website` snippets.
* B2B enforcement: `product.template._get_combination_info`,
  `_get_sales_prices`, `_website_show_quick_add` and
  `product.product._is_add_to_cart_allowed`.

## Extending

* New header: add a `<template inherit_id="website.layout" active="False">`
  replacing `//header//nav`, register its xmlid in
  `theme_aurora20/models/theme_aurora20.py` and in
  `static/src/builder/header_footer_option_plugin.js`.
* New storefront setting: add the field on `website`, its default in
  `AURORA_DEFAULTS`, and the field in `views/website_views.xml`.
* Never trust the browser for B2B: add new checks on the server side.

## Running tests

```bash
tools/run_aurora_tests.sh /path/to/odoo [database]
```

The browser tour needs Chrome or Chromium on the `PATH`.
