# Building blocks and homepage designs

## Building blocks

Website editor > **Blocks** > **Aurora** group:

| Block | Notes |
| --- | --- |
| Aurora Hero | headline, two buttons, three reassurance points, image with a badge |
| Promo Banners | two side-by-side campaign cards |
| Category Tiles | four image tiles linking to the shop |
| Services Bar | shipping, returns, support, secure checkout |
| Countdown Banner | timer to the date set in `data-end` (defaults to midnight); stops at zero |
| Brand Logos | published brands of the website, loaded when the page opens; `data-limit` (max 24) and `data-featured-only` |
| Customer Reviews | three review cards |
| Social Gallery | six-image grid |
| Newsletter Strip | call to action band |

Odoo's own **Products** block gets two more data sources: *Featured* (products
with a ribbon) and *On Sale* (products with a compare price).

## Mega menus

Edit a menu entry > **Mega menu** > template: *Aurora - Shop columns*
(categories, links and a promo card) or *Aurora - Featured links* (icon links).

## Homepage designs

Website editor > **+ New** > **Page** > **Aurora Homepages**. Ten complete
designs built from the blocks above and Odoo's blocks, with live product
carousels:

Fashion, Electronics, Furniture, Beauty, Grocery, Jewelry, Sports, B2B,
Minimal, Marketplace.

To make a new page the homepage: page properties > *Homepage*. The previous
homepage is kept.

## Product labels

Use Odoo's ribbons (product form > *Ribbon*): they are styled by the theme and
used by the *Featured* data source.
