# Upgrade notes

* Versions follow `20.0.x.y.z`. Update with `-u website_aurora20,theme_aurora20`.
* Theme templates customized in the editor are kept per website; Odoo only
  updates templates that were not edited.
* Homepage designs are regenerated on every update; pages already created from
  them are not changed.
* Brand data, product brands and storefront settings are kept on update.
