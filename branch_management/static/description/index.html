Multi Branch Management

One company, several branches: users, security, documents and numbering per branch

  • Branch master with hierarchy, per-company codes, address and logo
  • Allowed, default and current branch per user; systray branch selector
  • Server-side branch security on every document (ORM, RPC, URL and UI)
  • Multi-company aware: a branch always belongs to exactly one company
  • Integrations: Sales, Purchase, Inventory, Accounting, Manufacturing, Point of Sale, CRM, HR, Project, Contacts
  • Branch on printed documents, group by branch in every analysis
