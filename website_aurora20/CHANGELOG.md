# Changelog

## 20.0.1.0.0 (2026-10-01)

First release for Odoo 20.0.

* Product brands: model, backend, `/brands`, `/brand/<brand>`, shop filter, search results, brand logos block.
* Product quick view with variants, quantity, add to cart, wishlist and compare.
* Cart drawer with quantity controls, auto-open after add to cart.
* B2B mode enforced on the server (prices, add to cart), guest message, inquiry, wholesale info.
* Recent searches, announcement bar, product card styles.
* Nine building blocks, two mega menus, product data sources, ten homepage designs.
* Per-website settings with reset.
